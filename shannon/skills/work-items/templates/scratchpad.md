# Scratchpad

Capture point for ideas, half-formed work and unprocessed TODOs that don't yet belong to a work item.

**Format**: one line per item, optional `#tags`, no IDs, no status. Capture stays cheap: `/scratchpad-add [idea]` or a direct edit.

**Process periodically** with `/scratchpad-process`: work each item to one disposition — act on it within an approved Feature, promote it to a Feature (human decision) or an optional Epic, Task or Spike, move a durable finding to a knowledge note, or drop it. Record the disposition under Processed with a pointer to where it went. The scratchpad is not a backlog; an item that already has a clear home belongs there, not here.
